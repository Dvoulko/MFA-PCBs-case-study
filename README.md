# Material Flow Analysis (MFA) for E-Waste Management
## 🇬🇧 English Version

### Description

This project focuses on a comprehensive **Material Flow Analysis (MFA)** and mass balance system for e-waste management in Greece using **STAN** and **Eurostat** data, mapping Printed Circuit Boards (PCBs) and evaluating metal recovery. For the full description, methodology, and technical report, please refer to the referenced web documents.
You can read the comprehensive analysis, methodology, and conclusions of the study in the official PDF report:
